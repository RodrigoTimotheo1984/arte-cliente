# Arte Cliente

Skill do Codex que cria artes para Instagram e WhatsApp (feed e stories) com a cara do seu negócio.

## Como instalar
1. Abra o Codex.
2. Cole esta mensagem e envie:

   ```
   $skill-installer instale a skill https://github.com/RodrigoTimotheo1984/arte-cliente/tree/main/arte-cliente
   ```

3. Feche e abra o Codex de novo.

## Como usar
Abra uma pasta só para o seu negócio no Codex e escreva, por exemplo:

```
$arte-cliente quero divulgar a feijoada de sábado
```

Na primeira vez, a skill vai pedir a sua logo, alguns materiais e fotos reais do seu negócio. Isso acontece uma vez só.

## Sua marca fica com você
A logo, as fotos e as artes ficam guardadas só no seu computador, na pasta `marca-arte-cliente`. Nada disso vai para a internet.

## Se a instalação automática não funcionar
Copie a pasta `arte-cliente` para dentro de `C:\Users\<seu usuário>\.codex\skills\` (no Mac: `~/.codex/skills/`) e abra o Codex de novo.
